# 影片方向：《第 1 话：一按，即原画》

## 1. 参考拆解

用户没有给参考片，本节不写。

## 2. 产品气质

- **做什么、给谁、用起来的感觉**：给做网页的人用的一套组件。每一次点击都像动画里的一张原画：先蓄力再弹出，带特效、片假名拟声词和合成音效。气质轻快、俏皮、有冲击力，同时克制：可以关特效、关声音，动画走 `prefers-reduced-motion`。
- **设计语言**（来源 `src/core/tokens.js`、`src/core/palettes.js`、`site/site.css`）：纸白底 `#fbf8ff`，墨色 `#1b1642`，薰衣草紫和亮粉；3px 墨线描边；网点、集中线；平涂，没有渐变光效。字体：英文 Bangers，中文标题用站酷庆科黄油体，说明文字用 Comic Neue 配站酷快乐体，拟声词用 Chokokutai、Reggae One、Dela Gothic One、Mochiy Pop One。有 5 套配色，每套都有暗色。
- **母题候选**：漫画分格（コマ）和翻页；拟声词；集中线和网点；动画师的律表（timesheet）；"原画"这个名字本身。

## 4. 选择与理由

选 **A 一话漫画**，并借用一个 B 的律表镜头和 C 的冲击帧。理由：文档站已经是一本漫画杂志，观众看完片子打开仓库，看到的是同一套语言。B 太安静，压不住"每一下都有冲击"的卖点。C 的黑底会盖住产品的纸白和配色，而配色是这次要宣传的功能之一。

本片专属手法：

1. **因为**文档站本身就是漫画杂志（封面、章节扉页、分格、网点），**所以**整支片子是一话漫画：每个镜头是一页，组件放在分格里，换段用"翻页"和"格框砸入"。
2. **因为**每个组件都会自己打出拟声词、发出合成音，**所以**画面上的特效字就是组件自己打出来的（`sfx()`），音效轨就是组件实时发出的声音，用离线 AudioContext 录下，不另配音效素材。
3. **因为**库的动画都是烘焙进 CSS `linear()` 的弹簧（`SPRINGS`），**所以**影片自己的镜头运动和标题入场只用这四条弹簧，并有一个镜头把 `spring` 曲线画成律表。
4. **因为**作画风是"一拍二"的逐格动画（spinner、counter、flip loader 都是 steps），**所以**章节标题逐格出现，不做平滑淡入；换章时用 2 帧反色的冲击帧。
5. **因为**有 5 套配色 × 明暗，而且一行 `setPalette()` 就能切，**所以**配色镜头原地换色，不加转场遮挡：整页真实组件一起变色，同时打出那行代码，列表里的配色名弹一下。

与本工作区既往影片的区别：本工作区没有用这个 skill 做过的片子；`motion-studio/studio/films/ft` 是暗底科技风，本片是纸白漫画风、手法不同。

## 5. 画面规范

- 1920×1080，60 fps。页面按 960×540 CSS 像素排版、设备像素比 2，所以组件按原尺寸放大 2 倍，特效粒子也一起放大。底色是文档站的薰衣草网点纸，分格是白底 + 3px 墨框（成片 6px）。重要内容避开底部 13%（约 70 CSS px）。
- 字号阶梯（CSS px，成片 ×2）：英文大标题 Bangers 64 / 章节英文 44；中文标题 庆科黄油体 34；说明 Comic Neue + 站酷快乐体 15（成片 30px ≥ 22）；页码、标签 Bangers 13。
- 组件按原尺寸放 2 倍，正文 15px → 成片 30px；个别组件用 `size="lg"`。主题跟随文档站亮色，配色镜头再切暗色。
- 动效语法：入场用 `SPRINGS.bounce` / `spring`，镜头推拉用 `SPRINGS.soft`；标题逐格（steps）出现；换章冲击帧 2 帧。**不用**：平滑淡入淡出当主要转场、模糊、发光、彩虹渐变、3D 飞越。

## 7. 修订：干净版（2026-11-16，用户要求参考原片的素）

参考原片 `_ref/dl/video.fhls-1539.mp4`：白底、一次一个组件、灰色小标签、大量留白，特效是画面里唯一的装饰。据此改为：

- 去掉网点底纹、集中线、分格边框和投影；组件直接放在白底上，标签是分格左下角的灰色等宽小字。
- 标题不再装框：英文 Bangers 30 + 中文 19 的灰色副标题；说明文字去框，灰色 14。
- 多组件镜头一次只亮一个主角（其余淡到 22%），镜头结尾再全部亮起。
- 配色镜头取消七次网点擦除，改为原地换色；蒙太奇改为硬切，不再砸入。
- 每次换页都清掉顶层的拟声词；「シーン…」那一拍配乐完全静音（18.2–19.19 s）。
- Codex 评审：第一轮 7.5（`_review/codex/FILM-1.md`），第二轮 8.5（`FILM-2.md`）；第二轮剩下的日历点击回归和封面爆炸范围已修，未再送审。
